# datasets

Generated or checked-in data for tests and training.

- `test/`: small simulated SAC folders used by inference and evaluation smoke
  tests.
- `track_slot/`: default output location for TrackSlotNet tensor shard datasets
  generated by `generate_track_slot_dataset.sh`.
- `cache/`: optional cache output from older online training paths.

Generated data can be recreated and is not part of the model implementation.
